## Быстрый выбор сборщика

- Нужен **быстрый полный каталог без браузера** → `globus_collect.py`.
- Нужен **полный каталог с акциями** → `auchan_collect.py` (требует Camoufox
  из-за Qrator).
- Нужны **X5 (Пятёрочка / Перекрёсток)** → `pyaterochka_collect_v2.py`,
  `perekrestok_collect_v2.py`; ожидайте капчу и следите за `*_done.json`.
- Нужен **Чижик** → `chizhik_collect.py` (API, без DOM).
- Нужен **Дикси** → `dixy_collect.py` (DOM, самый простой из браузерных).

## Общие правила

1. Все сборщики можно перезапускать: состояние хранится в
   `*_links.json` и `*_done.json`.
2. Выгрузка всегда пишется в `*_products.json` в корне; крупные файлы
   покрыты `.gitignore`.
3. Для диагностики окружения — `smoke_env.py`, для проверки выгрузок —
   `final_check.py`.
4. Не запускайте два экземпляра одного сборщика одновременно: на Windows
  атомарная замена JSON может упереться в открытый дескриптор.

> Актуальные параметры запросов и поля всегда можно сверить с исходниками
> сборщиков — они компактные и самодокументируемые.
