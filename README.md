# grocery — сборщики товаров и цен сетей супермаркетов

**Набор автономных Python-парсеров для сбора каталогов и цен российских сетей супермаркетов.**

© 2026 RuChating (iilmchat) · grocery

---

## Что это

В репозитории лежит по одному самостоятельному скрипту на сеть: каждый собирает
товары, цены, изображения и категории и сохраняет результат в плоский
`*_products.json`. Общей библиотеки нет: скрипты копируют друг друга по
шаблону, чтобы их можно было запускать независимо и править точечно.

Есть два типа сборщиков:

- **API-сборщики** (`chizhik`, `globus`, `auchan`) — обращаются к внутренним
  API сайтов, быстрые и почти не нагружают страницы;
- **DOM-сборщики** (`dixy`, `pyaterochka`, `perekrestok`) — открывают страницы
  в Camoufox, прокручивают ленту до конца и читают карточки из HTML.

Цифры ниже — контрольные значения локальных выгрузок на **27.11.2026**.

## Требования

| Компонент | Версия |
| :--- | :--- |
| Python | **3.12+** (тестировалось на 3.12.10) |
| `camoufox` | 0.5.9+ (нужен DOM-сборщикам и Ашану) |
| `playwright` | 1.62+ (ставится зависимостью camoufox) |
| `scrapy` | 2.18+ (только для experimental-паука в `grocery/`) |
| Интернет | доступ к сайтам сетей; для Ашана — без блокировки Qrator |

Camoufox при первом запуске скачивает браузер (~200 МБ). Для API-сборщика
Глобуса браузер вообще не нужен.

### Установка

```bash
git clone https://github.com/iilmchat/grocery.git
cd grocery
pip install -r requirements.txt
python smoke_env.py            # проверка интерпретатора и Camoufox
```

Если Camoufox падает с `ValueError: Unable to create a ZSTDSeekContext`,
выполните один раз:

```bash
python fix_fpgen.py
```

Скрипт распаковывает повреждённый `fpgen/data/values.dat.zst` в обычный
`values.dat`, откуда fpgen читает данные без индекса.

## Быстрый старт

```bash
# Глобус — самый быстрый, без браузера (~30 секунд на категорию)
python globus_collect.py

# Ашан — через браузер с persistent-профилем profile_auchan
python auchan_collect.py

# Остальные сети
python chizhik_collect.py
python dixy_collect.py
python pyaterochka_collect_v2.py
python perekrestok_collect_v2.py
```

Каждый сборщик можно прервать `Ctrl+C` и запустить заново — он продолжит
с того места, которое записано в `*_done.json`. Глобус и Ашан пишут товары
атомарно после **каждой** страницы, поэтому при падении теряется не более
одного запроса.

Проверить результат:

```bash
python final_check.py
```

Скрипт считает количество записей, уникальных `product_id`, пропуски цен,
картинок и URL по всем локальным выгрузкам.

## Как это работает

### API-сборщики

| Сеть | Endpoint | Пагинация |
| :--- | :--- | :--- |
| Чижик | `GET /catalog/v2/stores/HBBN/categories/{cid}/overview` | по подкатегориям |
| Глобус | `POST /d1-front-bff/api-web/v1/catalog:product-list` | `per_page` до 1000 |
| Ашан | `POST /v3/catalog/products/?...&perPage=100&page=N` | 100 товаров на страницу, всего в `range` |

Глобус читает `browserAPIHost` и `uuid` из `__NEXT_DATA__` страницы
`/catalog/`, после чего работает через `urllib`. Ашан недоступен для
`urllib` (401 от Qrator), поэтому запросы идут через `fetch()` из контекста
Camoufox с сохранением кук в `profile_auchan/`.

### DOM-сборщики

Открывают страницу категории, ждут отрисовки, собирают карточки
(`article` у Дикси, `[data-qa^="product-card-"]` у X5) и прокручивают до
упора. У Пятёрочки и Перекрёстка есть отдельные `warmup_5ka.py` /
`warmup_pk.py` для прогрева профиля перед сбором.

### Формат результата

Общие поля: `retailer`, `product_id`, `name`, `category_path`,
`category_slug`, `url`, `image_url`, `price`, `scraped_at`. Подробности —
в [`docs/DATA_SCHEMA.md`](docs/DATA_SCHEMA.md).

Пример записи Глобуса:

```json
{
  "retailer": "globus",
  "product_id": "000000000000746791_ST",
  "name": "Каша ржаная Yelli яблоко-корица 60г",
  "category_path": ["Акции", "Бакалея", "Здоровый выбор"],
  "price": 73.99,
  "old_price": 99.99,
  "url": "https://online.globus.ru/products/kasha-rzhanaya-yelli-yabloko-koricza-60g-746791_ST/",
  "image_url": "https://image.globus.ru/mobile/57/97/4875797.jpg",
  "scraped_at": "2026-11-27T02:33:13.123456+00:00"
}
```

## Экспорт для эталонного формата 5ka

`make_export_5ka.py` превращает `pyaterochka_products.json` в набор файлов
`exports/5ka_<SAP>_<категория>_<время>.json.txt` схемы `schema_version: 1`:

```bash
python make_export_5ka.py
```

Поля `raw_text` в таком экспорте синтезируются из карточки, а не копируются
из DOM — это ограничение текущего сборщика.

## Диагностика и типичные проблемы

| Симптом | Причина | Лечение |
| :--- | :--- | :--- |
| `Unable to create a ZSTDSeekContext` | битый/неиндексированный `fpgen/data/values.dat.zst` | `python fix_fpgen.py` |
| `captcha` в HTML, 0 карточек | X5 поставила капчу на профиль | прогреть `warmup_5ka.py` / `warmup_pk.py`, повторить позже |
| Ашан отдаёт 401 | Qrator не пропустил новый профиль | удалить `profile_auchan/`, заново пройти челлендж в браузере |
| `PermissionError` при перезаписи JSON | другой процесс держит файл открытым | дождаться окончания второго прогона; в сборщиках есть ретрай |
| Сбор оборвался на середине | таймаут/падение сети | просто запустить скрипт ещё раз — продолжит с `*_done.json` |

Проверка окружения: `python smoke_env.py` (печатает интерпретатор и заголовок
тестовой страницы).

## Ограничения

- Цены зависят от выбранного магазина/адреса доставки и времени сбора —
  результаты следует считать снимком на момент `scraped_at`.
- Сборщики читают только публично доступные страницы; перед коммерческим
  использованием проверьте условия использования конкретного сайта.
- `Верный`: официальный сайт сети — `https://www.verno-info.ru/` (доступен),
  но это витрина с PDF-каталогами акций, а не каталог товаров с ценами.
  Товары и цены отдаёт API мобильного приложения
  `https://app.verno-dostavka.ru/api3/`, который требует токен, получаемый
  только после подтверждения телефона по SMS. После авторизации каталог
  товаров (≈31 тыс. название+картинка) доступен, но цены требуют выбранного
  магазина в API доставки, способ выбора которого пока не найден. Адрес
  `verny.ru`, фигурировавший в предыдущих выводах как «недоступный», к сети
  отношения не имеет (таймаут TCP). Подробности — в
  [`docs/COLLECTORS.md`](docs/COLLECTORS.md).
- `grocery/` — экспериментальный Scrapy-проект (пауки `chizhik`, `dixy`); основная
  разработка ведётся в standalone-скриптах в корне.
